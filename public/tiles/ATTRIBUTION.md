Mahjong tile SVG source

- Downloaded from: https://salasasa.cn/tiles/
- Tile filenames follow the Wikimedia Commons Cangjie6 Mahjong SVG naming style, for example `MJw1-.svg`, `MJt1-.svg`, `MJs1-.svg`, `MJf1-.svg`, `MJd1-.svg`.
- Reference source examples:
  - https://commons.wikimedia.org/wiki/File:MJw1-.svg
  - https://commons.wikimedia.org/wiki/File:MJt1-.svg
- License noted on Wikimedia Commons reference pages: Creative Commons Attribution-ShareAlike 4.0 International.

This project keeps the files locally so the game can be deployed on a 1Panel server without depending on external image requests.
