# 青桌麻将

当前版本：`1.8`

浏览器可玩的四人麻将，支持单人电脑局与在线房间。当前按项目根目录的 `胡牌规则.md` 实现东光玩法试做规则。

## 当前功能

- 单人开局：1 名玩家对 3 名电脑。
- 在线房间：创建房间、复制房间号、好友加入、补电脑和连续开局。
- 完整摸打：发牌、摸牌、出牌、碰牌、点炮、自摸、荒庄；有碰，没有吃。
- 明示路线：自己摸到第三张并组成完整边/钻顺子后才能“钻了”；三碰胡/四碰胡使用“上摞”；明示后锁定对应胡法。
- 摞牌展示：钻/边组与上摞刻子均按“下方两张紧挨、第三张置于交界处上方”显示。
- 胡法：普通胡、清一色、七对、豪华七对、一条龙、钻胡、三碰胡、四碰胡、十三不靠、十三幺。
- 响应式牌桌：桌面、手机竖屏、手机横屏和 320px 小屏均使用独立空间布局。
- 牌面素材：34 张本地 SVG 麻将牌，不依赖外站加载；本版没有修改牌面文件。

## 暂定积分

- 庄家底分 `2`，闲家底分 `1`。
- 清一色 `8`，七对 `4`，豪华七对 `6`，一条龙 `4`。
- 十三不靠 `8`，十三幺 `13`。
- 三碰胡 `4`，四碰胡 `8`，钻胡 `6`。
- 自摸时每家支付“底分 + 胡法分”的两倍。
- 点炮时由点炮者包三家，支付“底分 + 胡法分”的三倍。

积分值仍可按当地实际玩法继续调整，胡牌结构与明示时机以 `胡牌规则.md` 为准。

## 版本归档

- `versions/1.0`：第一版 MVP。
- `versions/1.1`：积分系统和牌面 UI 改版。
- `versions/1.2`：按参考图重画麻将牌面。
- `versions/1.3`：改为 SVG 矢量牌面。
- `versions/1.4`：接入并本地化 salasasa.cn 同款公开 SVG 麻将牌素材。
- `versions/1.5`：完整接入当前胡法、碰牌与两条明示路线，重做桌面和手机牌桌体验。
- `versions/1.6`：修正钻/边明示时机，改为自摸第三张、完整顺子成立后直接明示并摞牌。
- `versions/1.7`：重构手机横竖屏、固定手牌与弃牌槽，增加唯一牌 ID、摸牌/最新弃牌标记和退出房间。
- `versions/1.8`：摸牌回归正常排序，弃牌网格锚定中央字框，移除牌背白边，并按来源隐藏钻/边和暗刻上摞。

## 本地运行

```bash
npm test
npm start
```

打开 `http://localhost:3019`。

## 1Panel 部署

当前 Docker 部署包仍为已确认的 v1.7，见 `DEPLOY-1PANEL.md`。v1.8 待网页审阅通过后再生成新的 1Panel 包。
