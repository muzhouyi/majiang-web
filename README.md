# 青桌麻将

当前版本：`1.5`

浏览器可玩的四人麻将，支持单人电脑局与在线房间。当前按项目根目录的 `胡牌规则.md` 实现东光玩法试做规则。

## 当前功能

- 单人开局：1 名玩家对 3 名电脑。
- 在线房间：创建房间、复制房间号、好友加入、补电脑和连续开局。
- 完整摸打：发牌、摸牌、出牌、碰牌、点炮、自摸、荒庄；有碰，没有吃。
- 明示路线：钻胡使用“钻了”，三碰胡/四碰胡使用“上摞”，明示后锁定对应胡法。
- 摞牌展示：钻/边组与上摞刻子均按“下方两张紧挨、第三张置于交界处上方”显示。
- 胡法：普通胡、清一色、七对、豪华七对、一条龙、钻胡、三碰胡、四碰胡、十三不靠、十三幺。
- 响应式牌桌：桌面、手机竖屏、手机横屏和 320px 小屏均使用独立空间布局。
- 牌面素材：34 张本地 SVG 麻将牌，不依赖外站加载；本版没有修改牌面文件。

## 暂定积分

- 庄家底分 `2`，闲家底分 `1`。
- 清一色 `8`，七对 `4`，豪华七对 `6`，一条龙 `4`。
- 十三不靠 `8`，十三幺 `13`。
- 三碰胡 `4`，四碰胡 `8`，钻胡 `6`。
- 自摸时每家支付“底分 + 胡法分”的两倍。
- 点炮时由点炮者包三家，支付“底分 + 胡法分”的三倍。

积分值仍可按当地实际玩法继续调整，胡牌结构与明示时机以 `胡牌规则.md` 为准。

## 本地运行

```bash
npm test
npm start
```

打开 `http://localhost:3000`。

## 1Panel 部署

1. 把整个项目上传到服务器，例如 `/opt/majiang-web`。
2. 在 1Panel 的“容器 / 编排”中创建 Compose，选择项目里的 `docker-compose.yml`。
3. 启动编排后访问服务器 `3000` 端口，或在 1Panel 网站中建立反向代理并绑定域名。
4. 使用 HTTPS 域名时，前端会自动通过 `wss://` 建立在线房间连接。

当前房间状态保存在单个 Node 进程内。生产部署先保持单副本运行；后续如需多实例，再接入 Redis 保存房间状态。
