# 青桌麻将

当前版本：`1.1`

一个网页能玩的麻将 MVP，支持：

- 单人开局：1 名玩家对 3 名电脑。
- 联机房间：创建房间、复制房间号、好友加入、补电脑、开局。
- 基础摸打流程：发牌、摸牌、出牌、点炮、自摸、荒庄。
- 东光/沧州暂定积分：庄闲底分、自摸翻番、点炮包三家、七对、豪华七对、碰碰胡、清一色、一条龙、捉五魁、边钻暂定。
- 图案牌面：筒、条、万、风牌、箭牌使用 SVG 牌面图案，不再用纯文字代替。

## 版本归档

每次改版都会放到新的版本文件夹：

- `versions/1.0`：第一版 MVP 记录。
- `versions/1.1`：本次积分系统和牌面 UI 改版快照。

## 本地运行

```bash
node server.js
```

打开 `http://localhost:3000`。

## 1Panel 部署

推荐用 1Panel 的“应用商店 / Docker Compose / 编排”方式部署：

1. 把整个项目上传到服务器，例如 `/opt/majiang-web`。
2. 在 1Panel 里新建 Docker Compose 编排，选择这个目录里的 `docker-compose.yml`。
3. 启动后访问服务器 `3000` 端口，或在 1Panel 反向代理里绑定域名。
4. 如果使用 HTTPS 域名，浏览器会自动使用 `wss://` 连接联机服务。
