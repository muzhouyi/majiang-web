# 青桌麻将

当前版本：`4.0`

浏览器可玩的四人麻将，支持单人电脑局与在线房间。当前按项目根目录的 `胡牌规则.md` 实现东光玩法试做规则。

## 当前功能

- 单人开局：1 名玩家对 3 名电脑。
- 在线房间：创建房间、复制房间号、好友加入、补电脑和连续开局。
- 完整摸打：发牌、摸牌、出牌、碰牌、点炮、自摸、荒庄；有碰，没有吃。
- 杠牌：支持明杠、暗杠、补杠、杠后补牌和杠上开花。
- 明示路线：自己摸到第三张并组成完整边/钻顺子后才能“钻了”；三碰胡/四碰胡使用“上摞”；明示后锁定对应胡法。
- 摞牌展示：钻/边组与上摞刻子均按“下方两张紧挨、第三张置于交界处上方”显示。
- 胡法：普通胡、清一色、七对、豪华七对、一条龙、钻胡、三碰胡、四碰胡、十三不靠、十三幺。
- 响应式牌桌：桌面、手机竖屏、手机横屏和 320px 小屏均使用独立空间布局。
- 牌面素材：34 张本地 SVG 麻将牌，不依赖外站加载；本版没有修改牌面文件。

## 暂定积分

- 赢家积分为“（普通胡分或全部成立胡法分）×（基础倍率 × 庄家倍率 × 自摸倍率）＋杠得分”。
- 默认基础倍率为 `1`，庄家倍率和自摸倍率均为 `2`。
- 普通胡 `1`，清一色 `8`，七对 `4`，豪华七对 `6`，一条龙 `4`。
- 十三不靠 `8`，十三幺 `13`；三碰胡 `4`，四碰胡 `8`，钻胡 `6`。
- 明杠、暗杠和补杠只在动作发生时记录，到本局结束时统一结算。
- 没有胡牌但取得杠分的玩家，也会在局末得到相应积分。

积分值仍可按当地实际玩法继续调整，胡牌结构与明示时机以 `胡牌规则.md` 为准。

## 本地运行

```bash
npm test
npm start
```

打开 `http://localhost:3019`。

## 1Panel 部署

当前可直接部署的 Docker 压缩包仍为 v3.1，见 `DEPLOY-1PANEL.md`。v3.2 先作为审阅版保留，确认无误后再生成新的 1Panel Docker 部署包。

当前房间状态保存在单个 Node 进程内。生产部署先保持单副本运行；后续如需多实例，再接入 Redis 保存房间状态。
